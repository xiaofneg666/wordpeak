00 · HOW TO USE

这份文档怎么用

不是页面清单，是 UI 设计的功能底稿。先建立全局关系，再进入单页。

词峰不是「二十个独立页面」，而是一个连续的学习宇宙：观星台是总控，词汇圣殿是中心空间，技能舱是训练场，书库是长内容，暗物质区把一切结果收回来。 设计任何一页之前，先回答它在哪条路径上、上游是谁、下游把数据交给谁。

STEP 01
先看关系图

搞清楚 8 个主导航、工具菜单、全局复习层和数据核心的关系。不要从单页开始画。

STEP 02
再走主路径

新用户、每日 15 分钟、输入、输出、读书、错题修复——每条路径决定页面的主 CTA 与空态。

STEP 03
最后逐页设计

每张卡有定位 / 功能 / 数据 / 入口出口 / UI 提示。先画 Operate 的任务流，再决定 Experience 的表达。

02 · MAIN JOURNEYS

八条主路径

UI 设计的真正单位是「用户要走完的一条路」，不是单个页面。

JOURNEY 01

新用户第一次进入

官网开场进入宇宙观星台新手首课 / 今日航线学习舱复习

先给一个可完成的 5 分钟动作，再展示全貌。

首课完成 → states / stats 更新
JOURNEY 02

每日 15 分钟

观星台今日航线学习舱新词复习到期回观星台

一条不会做错的默认路径；卡住时永远能回到观星台。

review results → FSRS → stats
JOURNEY 03

词汇深挖

词汇圣殿点星开词档案加入复习 / 收藏 / 看词根

从「看到一颗星」到「带走一个词」不超过两次点击。

learnWord / collections → states
JOURNEY 04

输入训练

回声谷或阅读号选语料精听 / 精读点词进复习结算

输入页的核心是「听顺 / 读懂」，不是完成题量。

listening / reading results → stats / mistakes
JOURNEY 05

输出训练

口语竞技场或写作工坊选语料 / 抽目标词录音 / 写作AI 反馈暗物质区

输出必须先给具体反馈，再谈分数。

speaking / writing results → stats / mistakes
JOURNEY 06

读书闭环

轨道书库双击书脊夜读舱翻页点词卡加入复习回书库

书是长内容，词卡是旁注；不要让工具打断阅读。

read marks + learnWord → library / states
JOURNEY 07

错题修复

暗物质区选 tab深链到具体条目重做结果回写

深链必须落到「这一题 / 这一篇 / 这个词」，不是模块首页。

grammar / passage / writing results → stats
JOURNEY 08

词汇研究 / 自由探索

词汇网络词根群星收藏夹全量词库

允许无目的游荡；搜索结果要能迅速收束成行动。

network / collections / lexicon → 词卡

02 / 21 入口与总览 view: dashboard

观星台

THE OBSERVATORY

个人学习总控台。一屏回答：今天学什么、我已经走到哪、哪里最弱、下一步点哪里。

Operate拨盘 4 / 4 / 6
核心功能 / WHAT IT DOES
  • 问候 + 实时时钟 + 学习摘要 + 连续天数；Hero 主 CTA「继续航线 / 按推荐启程」。
  • 今日航线：新词 / 复习 / 补弱三节点，来自档案 + 到期队列 + 弱项。
  • 三条学习模式：快闪 5 分钟 / 标准 / 远征；推荐档按时段与进度决定。
  • 你的天空（星图速写）+ 星轨（7 站坚持），一人一份的成长证据。
  • 新手首课入口（3D 房间 + 目标选择）；智能提示卡（到期 / 连胜 / 告急 / 新号）。
  • 三数字磁贴：已点亮 / 真正掌握率 / 今日到期；今日一策（推荐 API + 中文理由）。
  • 画像区：星系五态分布、模块正确率、词汇量增长、记忆强度五桶、全年热力图。
  • 每日任务 / 成就墙、近 N 天练习量、最弱词根、推荐模块、英语书单 rail。
  • 周报弹窗：本周 streak / 掌握 / 新学 / 出勤 / 弱项，可导出 PNG。

07 · UI CHECKLIST

交付前检查清单

每一页都按这张表过一遍；缺一项就是半成品。

全页面状态 — loading 骨架 / empty / error / success / disabled 五种状态都画。

数据真实 — 所有数字必须来自 API 或明确示例；不造 92% / 4.8× 这类精确假数。

新号零态 — 观星台 / 统计 / 写作历史 / 收藏夹等零数据页面，先给行动，不先给空图表。

3D 降级 — 圣殿 / 书库 / 官网 / 环境层都要有 WebGL fallback；隐藏时停帧。

音频状态 — 权限拒绝 / 识别不支持 / 录音中 / 评分中 / 重听，逐句都要有。

正文可读 — Read 表面 65–75 字符/行（中文 30–45 字/行）；对比度 AA。

触屏 44px — 所有主要按钮、tab、书脊、词卡在触屏上至少 44×44px。

键盘可达 — Cmd/Ctrl+K、Esc、? 帮助；焦点可见；词卡 / 抽屉可键盘关闭。

减少动态 — 过场跳过、循环停播；只保留静态星图 / 静态帧。

状态不只靠色 — 五态词星同时用文字 / 图例 / 形态；不要只靠红绿。

危险操作 — 删除收藏夹、清空进度、导入覆盖：二次确认 + 备份提示。

移动端结构 — 不是缩字号：收导航、换单列、书库 / 网络给列表 fallback。
