六大知识模块
听说读写 + 词汇 + 语法,六大场景对应不同学习行为;不是拼凑,每一条路径都对得起费曼输出法的"输入 → 内化 → 输出"。
词汇星系
461 个单词按 40 个词根家族聚成星系,SM-2 间隔重复驱动星球光线的衰减与重亮,点词即学、双击家族锁定看该家族全景。
发音舱
48 国际音标的口腔矢状面剖面图(舌位、唇形、声带),听辨测试分级 + 拼读规则 14 条 × 3 题 + 跟读波形真实采样。
语法机械城
21 个语法点 × 9 题闯关 + 机械装配车间(拖拽零件验证句子结构),时态=齿轮组、虚拟语气=霓虹电路,机械感与抽象概念对齐。
听力峡谷
26 篇分级语料共享波形条,语速 0.6–1.2 倍可调 + 长按单句进入 AB 循环,精听一个生难点而不被全篇干扰。
口语竞技场
逐句跟读 + Web Speech API 实时识别 + 音素级相似度比对,双轨波形(示范 vs 你)显示未读/多读区段,AI 教练按句给改进建议。
阅读号列车
分级短文像翻书虫读物,点词即学自动进复习队列 + 句句可朗读 + 读后理解题结算 WPM 与年级目标对比。
四步学习路线
从发音到开口,把听 / 说 / 读 / 写的关键节点拆成 4 段。路线不是死规定,允许跳过已掌握的部分。
1
音标关
第 1–2 周
先把 48 个音标读准。音标不准,听力永远跟不上 — 你听到的和你以为的不一样。
2
语法框架
第 3–4 周
不求背完 21 个语法点,能看懂句子结构就行;是阅读与听力的地基。
3
输入关
第 5–10 周
读和听一起上,单词放进语境里记;每天该复习哪些词,SM-2 算法替你排好。
4
输出关
第 11 周起
跟读、造句、写短文,把积累用出来。学习画像告诉你哪个模块弱,回头补。
背后的学习方法论
所有功能都对得起一条学习科学;不是"看着酷"的设计。
SM-2 间隔重复
每个单词星球的亮度由记忆强度实时驱动,刚学会明亮,按艾宾浩斯遗忘曲线衰减,即将遗忘发红色求救光。
词根联想网络
461 词按 40 词根聚簇(spect- / port- / dict-...),记一个词根 = 点亮一串,学的是网络不是列表。
i+1 可理解输入
分级语料按答题表现推送"刚好够得着"的内容;不浪费也不会卡死。
错题流动系统
语法 / 听力 / 阅读 / 写作错题全进错题本,自动按家族聚合,跟踪到连续答对才"结案"。
费曼输出法
口语跟读 + 写作工坊,把输入倒逼出来,输出模块的正确率反哺词汇推送策略。
学习画像
词汇量增长曲线 / 强度分布 / 最薄弱根 / 周报 PNG,可视化你的进步曲线。
