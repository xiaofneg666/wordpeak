# WordVerse 视觉体验升级 · 全站体检 + 逐页改造方案

> 状态：第一阶段分析完成，待用户批优先级后执行（2026-10-14）
> 方法：3 个并行审计代理全读 18 个视图源码 + 样式系统核查 + 历史病历（2026-10-12 调研报告）修复情况复核
> 红线（用户 brief）：不重新设计产品、不加没必要的新功能、不做概念 Demo——只对已有功能做真实改造，目标=世界级数字体验品质

## 第一阶段 · 页面清单（18 个视图）

导航结构：`LEARN_TABS` 8 项平铺（词汇圣殿/学习舱/发音舱/语法机械城/口语竞技场/阅读号列车/写作工坊/英语日记）+ `TOOL_TABS` 8 项收进「工具」下拉（观星台/记忆工坊/技巧库/书籍馆/词汇网络/收藏夹/暗物质区/设置）。无 vue-router，Pinia `store.view` 切换 + `?view=` 深链白名单。

### ① 观星台 DashboardView（首页）
- **目的**：学习画像总览 + 今日行动入口
- **任务**：知道今天学什么 → 看见自己的宇宙 → 进入任意模块
- **视觉问题**：14+ 区块信息密度极高（hero→今日航线→你的天空→新手卡→insights→三磁贴→今日一策→星系分布→模块正确率→增长曲线→强度分布→全年热力→DailyQuests→练习量→最弱词根→推荐→书单）；insights 卡用 emoji 图标（⏰🔥🌱🏆✦🛰️）与全站自绘天文仪器语言冲突；「学习轨迹/里程碑」这类激励内容埋在设置页而本页另有 insights 里程碑 + DailyQuests 成就——**三套成就系统 localStorage key 互不认账**（wv_achievements / wv_milestones / wv_milestone_n）
- **交互问题**：**死点击**——「今天要复习的」磁贴点了还在本页（应 openReview）；星系分布行点击不带过滤参数；强度分布 chip 硬编码「461 词里」；周报 PNG 固定晴空配色无预览；练习量图无数据时图例仍然渲染成半空卡

### ② 词汇圣殿 GalaxyView（3D）
- **目的**：数据即世界——461 词星、滚动=航行、点星=解封词档案、终幕我的星座
- **任务**：漫游探索 → 解封词 → 星火问答点亮 → 终幕星座导出
- **视觉问题**：HUD 图例只有 3 态（未学/学习中/已掌握），全站其余口径是 5 态（critical/due 独立红/琥珀），圣殿里「记忆告急」的星无法分辨；构建遮罩是 700ms 假加载定时器；600px 以下航路刻度轨直接 display:none；操作提示 10.5px 一行小字易被忽略
- **交互问题**：飞行/终幕/选中词状态不进 URL，刷新即回开场；「双击家族锁定」无 undo 提示；新号 0 词终幕只有灰文案，几乎无内容
- **注**：本页已有六幕航行 + 终幕星座 + 星图导出（前几轮已实施），是全站体验基准

### ③ 学习舱 LearnView（核心学习）
- **目的**：新词「编码→回忆→巩固」三幕教学闭环（FSRS）
- **任务**：学一批新词，每词走完三幕
- **视觉问题**：三幕刻度是纯文字「编码·回忆·巩固」，无连续进度轨道；idle 词 chip 墙是静态灰边胶囊未按记忆状态着色；EncodeAct 五个内容块（词根拆解/故事/谐音/例句/搭配）纵向平铺无分层，是核心学习页却基本纯文字+CSS
- **交互问题**：空态是一行内嵌链接没用 EmptyState；RecallAct 自评 known 派发 `wv:wordLit` 事件但用户在流程内**看不到任何画面回应**（学习即点亮的因果断了最后一环）

### ④ 发音舱 PhoneticsView（视觉资产最厚）
- **目的**：48 音标——解剖+跟读打分、最小对立体听辨、拼读规则三关、掌握度热力
- **任务**：学会一个音 → 跟读验证 → 听辨/拼读巩固
- **视觉问题**：rules 模式 14 张规则卡无总进度可视化（只靠卡边框变绿）；四模式 tab 纯文字胶囊无图标；跟读反馈只有一行字+百分比无分数环；mastery 热力图只有 title 提示、不可点击直达跟读
- **交互问题**：hover 词卡用 fixed 定位+鼠标坐标，表格边缘/移动端不可用

### ⑤ 语法机械城 GrammarView
- **目的**：语法点=机器，公式→装配动画→拖拽装配→闯关，错题入档
- **任务**：找到目标语法点 → 弹窗内学+装配+答题
- **视觉问题**：机器卡 grid 无分类筛选（chip 只展示不可点），16+ 语法点只能扫读；EmptyState 传 `emoji=""` 大字水印不渲染；家族关系图是静态 SVG（对比 NetworkView 力导向图）
- **交互问题**：详情弹窗六段纵向排列需滚 88vh 无步骤导航；GrammarFamilyGraph 固定 960×384 viewBox + min-width:700px 小屏横滚；装配 +10 分是会话局部变量不持久、不与 mastery 环联动。**机器运转仪式（全对时 MachineBelt 转起来）是全站答对反馈最佳范本，应推广**

### ⑥ 回声谷 ListeningView
- **目的**：精听——慢速进、单句循环、听后做题
- **任务**：选信号 → 逐句听懂 → 做题验证
- **视觉问题**：signal-row 声纹选单是全站最佳列表语言（但仅此页专属）；canvas 波形是伪波形（按文本确定性生成）游标可能不同步；选中篇后选单退化成普通 pill，两种形态不统一
- **交互问题**：**中文翻译无条件常显**——精听场景译文应默认收起（ReadingView 有 showZh 开关这里没有）；无「这句没跟上」主观标记沉淀弱句清单；错题解析纯文字不能一键循环对应句；结算只有一行字+chip 无图形

### ⑦ 口语竞技场 SpeakingView（听说读写中最丰富）
- **目的**：影子跟读——听示范→跟读→逐词音素级比对
- **任务**：逐句练跟读，看命中/未命中
- **视觉问题**：选篇是平铺 pill，无 signal-row 级选单形态；示范轨波形是按词生成的伪包络（注释自认）
- **交互问题**：**只有逐句分，8 句练完没有全篇聚合视图**（平均分/完成度/「这篇过了」的收束感），scores 只存内存换页即失；**用户录音不能回放**（只留能量条）——「听自己读的」关键反馈缺失；无历史成绩对比

### ⑧ 写作工坊 WritingView（五技能视图中的视觉洼地）
- **目的**：费曼输出——造句+成文，规则打分+AI 批改
- **任务**：抽目标词写 → 提交 → 看批改
- **视觉问题**：整页一张大卡，无卡片化结构、无任何图形元素，视觉密度全站最低与「工坊」命名不匹配；打分只有静态圆环数字，6~7 个加权维度无可视化；AI 教练卡与规则打分卡并列重复信息层次弱
- **交互问题**：**批改与原文割裂**——错误位置全靠脑内对位，原文上无任何划线/高亮；无写作历史（旧文被「换一个」覆盖）；textarea 无自动保存、成文 40 词目标只有两个裸数字无进度可视化

### ⑨ 阅读号列车 ReadingView
- **目的**：i+1 可理解输入——分级短文逐句精读、点词即学、测 WPM
- **任务**：选篇 → 逐句读（点词/看翻译/听朗读）→ 做题 → WPM 结算
- **视觉问题**：车厢隐喻是差异化亮点（看过翻译车厢变绿、已学词正文内变绿）；但**无阅读进度指示**——读到第几句车厢不知道；已读时长是 dim chip 存在感低；WPM 面板只在结算时出现
- **交互问题**：**错题不能一键跳回原文对应句**（解析只是一行文字）；localStorage 攒了每篇累计时长/最佳 WPM 但没有任何地方展示；篇目选单平铺无难度视觉分层

### ⑩ 书籍馆 BookshelfView
- **目的**：教材推荐——六大类书单 + 四步路线，书映射到站内模块
- **任务**：挑一本值得练的书 → 跳去对应模块
- **视觉问题**：书架悬停抽书是全站最有实体感的交互；但书卡无封面全文字，一页 20 本视觉重复度高；页面长无锚点导航/类别吸顶
- **交互问题**：**纯静态零个人化**——不记录在读/读完；书脊悬停物理效果触屏完全不可用（无 pointer 降级）；无搜索/筛选；星级难度不可交互

### ⑪ 词根群星 FamilyView
- **目的**：40 词根家族索引 + 词源故事 + 整族复习
- **任务**：挑家族 → 读词源故事 → 复习整族
- **视觉问题**：**词源故事是纯文字段落——全站最可惜的可视化缺口**（SkySketch/ForceGraph/GrammarFamilyGraph 三个图组件都没用上）；索引卡不显示任何掌握进度，无法挑「我快忘最多的」族；详情态丢掉 terr-head 领地页头
- **交互问题**：40 家族无搜索/排序；3 块 stat-tile 孤立大数字无分布条

### ⑫ 暗物质区 MistakesView
- **目的**：聚合六模块错题，「错题不是污点，是暗物质」
- **任务**：看错题 → 重做消灭它
- **视觉问题**：dm-star 暗星语言好；但六个 tab 内容形态割裂（vocab 三列卡片网格 vs 其余五 tab 同一套灰底行）
- **交互问题**：**「重做一题就有一颗星亮起来」叙事无闭环**——没有任何已重做标记机制，暗星永远只 hover 亮，列表只增不减；错题行不展示原文/你的答案/正确答案，页内不能直接重做；列表硬切 30/50 条无分页无错因归类；writing「再写」不带语料深链；词库错题只收 due && strength<0.45，没到期但错过的词永远不进

### ⑬ 收藏夹 CollectionsView
- **目的**：跨家族生词夹 + 导出（CSV/Anki/JSON）
- **任务**：管理生词夹 → 复习/导出
- **视觉问题**：**夹卡信息量极低**——色点+名字+词数+日期一排几乎一样，无 critical/due 分布 mini-bar、无预览词；夹内态丢领地页头
- **交互问题**：**本页无法新建收藏夹**（空态教你去词汇星系点 ★）；夹内无搜索/排序/**无复习整夹**（错题本和家族都有整族复习，收藏夹反而没有）；导出无预览全靠 toast

### ⑭ 技巧库 TipsView
- **目的**：48 条方法论卡片 + 深链去练
- **任务**：找一条有用的技巧 → 跳去练
- **视觉问题**：**48 张卡片同构同权重纯文字瀑布流**，无精选置顶、无视觉锚点，滚动疲劳；L{level} 徽章无 tooltip 解释；搜索无命中高亮
- **交互问题**：展开步骤后卡片撑破网格行高节奏；窄屏搜索框与 tab 换行挤压

### ⑮ 英语日记 DiaryView
- **目的**：中文日记 → AI 逐句译英 → 跟读打分 → 历史
- **任务**：写 → 翻译 → 逐句跟读 → 回看
- **视觉问题**：历史区纯文字行无任何统计/时间线仪式感（累计句数/坚持天数）
- **交互问题**：**翻译失败 banner 把开发者运维文案直接暴露给用户**（「在 backend-node/.env 填入 ANTHROPIC_API_KEY…」）；历史无搜索/按月分组；跟读成绩不落库无法回看对比

### ⑯ 记忆工坊 LabView
- **目的**：四种记忆方法各一节「原理→互动→我的数据」
- **任务**：理解方法 → 现场互动演示 → 去实践
- **视觉问题**：**五个视图里最「文章化」的一页**——lab-p 纯文字段落纵向平铺、行高 1.95；四法导航格无图标；词根装配互动只有文字 chip+一行变色（对比 GrammarAssembly 有齿轮运转 SVG，同类互动体验差距明显）；遗忘曲线 SVG 无网格无刻度无 hover 读值
- **交互问题**：「我的数据」块与正文无区分度；risky 词卡点击无 hover 外反馈

### ⑰ 词汇网络 NetworkView（交互最丰富）
- **目的**：461 词/40 家族语义共现力导向图自由探索
- **任务**：探索共现关系 → 点词开词卡
- **视觉问题**：图例 11px mono 贴画布左下角近乎不可见；控件栏零散无卡片包裹；空态文案暴露后端调试信息（「检查 GET /api/words/network 是否返回 200」）
- **交互问题**：选中词的回显只是底部一行小字，无侧栏/面板；无 zoom 控件按钮；Canvas 只绑 mouse 事件**触屏基本不可用**；无小地图/聚合，461 节点全量平铺

### ⑱ 设置 SettingsView
- **目的**：主题/语速/FSRS 偏好 + 数据管理 + 学习轨迹
- **任务**：调偏好 / 导出数据
- **视觉问题**：**「学习轨迹」（里程碑+周柱图）埋在设置页是最反直觉的信息架构**；里程碑图标用 emoji（🌱🔥📅⭐🏆）违反「UI 不加 emoji」既定纪律；资源卡数字全部硬编码（关于卡却是动态的，同页两种口径）；danger 按钮与 primary 导出按钮并列混排
- **交互问题**：里程碑解锁靠用户手动点卡片才触发 toast，自动达成无提示；三套成就系统各自为政（见①）

## 第二~四阶段 · 功能→体验重设计（按功能设计，不套统一风格）

设计裁决沿用 CREATIVE-DIRECTION.md：**记忆即光**。已确立的全站语汇：`terr-head` 领地页头 / `signal-row` 信号行 / `dm-star` 暗星 / `unsealRise` 阶梯解封 / `conic` 掌握环 / 金色 #f2ead8 = 点亮。每页方案只做减法和补环，不发明新隐喻。

### 参考案例转化表（Phase 4）

### 逐页方案（Phase 2-3）

#### 1. 观星台（P1 首页）
- 用户目标：今天学什么 + 我的宇宙长什么样
- 学习问题：动机维持、行动入口清晰度
- 体验形式：**观星台**（保留）——数据即天文
- 改造：
  - **「今日星况」聚合**：TodayRoute 升格为开场行动面版（一个主行动大按钮 + 三个次行动），三磁贴/insights/DailyQuests 中重复的信息合并
  - **三套成就系统统一为一套「星轨」**（localStorage key 统一、Settings 学习轨迹迁移上来成为「星轨」区块，与 SkySketch 相邻——天上星图 + 地上轨迹呼应）
  - 死点击修复（openReview）、硬编码数字动态化、emoji→仪器 SVG、无数据图例不渲染、周报加主题预览
  - 技术不改架构，纯 Vue computed/CSS

#### 2. 学习舱（P2 核心）
