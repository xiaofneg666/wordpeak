# 设计操作标准 · WORDPEAK 词峰

> 状态：已生效（2026-10-19 起所有 UI 改动遵循）
> 来源：综合四份外部设计技能（frontend-design / impeccable / design-taste-frontend / ui-ux-pro-max）+ 项目 15 轮审美反馈沉淀（见 `~/.claude` 项目记忆 wordpeak-project）+ 宿主 web-design 基线。
> 用法：动手前过 §1 设计读法；写码时守 §2-§5；交付前跑 §6 Pre-Flight。冲突裁决见 §7。

## 1. 设计读法（动手前先回答，一句话写进开工说明）

**"读作：__视图（__表面模式），词峰深空语言，拨盘 __/__/__。"**

### 1.1 表面模式（按表面分，不按页面分 —— impeccable 核心）

| 词峰表面 | 模式 | 裁决原则 |
|---|---|---|
| 词汇圣殿 / instruments | **Experience** | 作品领队，界面退后；动效只在强化探索处用 |
| 首页 hero / 落地叙事 | **Persuade** | 首屏一个论点，主行动 unmistakable |
| 学习舱 / 回声谷 / 夜读舱 / 错题本 / 观星台统计 | **Operate** | 任务完成优先；装饰不得与工作抢眼睛 |
| Tips / 词源故事 / 阅读正文 | **Read** | 排版与理解优先，正文 65-75 字符/行 |

装饰量按模式定：Experience 可以挣表达，Operate 里表达必须消失。历史上"晴空看不清"的根源就是 Experience 层装饰溢到了 Operate 表面。

### 1.2 三拨盘（taste-skill 词汇，词峰当前定值）

| 表面 | VARIANCE | MOTION | DENSITY |
|---|---|---|---|
| 圣殿 / instruments | 8 | 7 | 3 |
| 首页 hero | 7 | 5 | 4 |
| 学习 / 练习页 | 4-5 | 3-4 | 5-6 |
| Read 类正文 | 5 | 2 | 4 |

改样式时先声明拨盘值；"美化学习页"永远不意味着给 Operate 表面加 Motion。

### 1.3 词峰是 refinement，不是 redesign

项目已有成熟设计系统（styles.css v5 深空宇宙风 + terr-head 领地语言 + 星图命名式排版）。**缺设计文档不等于白纸**——继承既有体系是默认，只有用户明说"重做"才允许换视觉语言。改动的判断标准是"当前身份保留住了吗"，不是"有没有新意"。

## 2. 词峰的设计语言（继承清单——定死，不每次重选）

- **色彩令牌**：基底 `#05070f`，accent 青 `#22d3ee` / 紫电 `#a78bfa` / 品红 `#f472b6`；金 `#f2ead8` 只表达"已学/读完/点亮"语义；晴空下金换暗琥珀 `#b45309`。一切取色走令牌，不手调新色。
- **字号/间距/圆角**：只用 `--fs-*` / `--sp-*` / `--r-*` 阶，不发明档位外数值；圆角一套体系（圆角混用=破）。
- **排版语言**：星图命名式 = mono kicker（字距 0.4em）→ 衬线大字 → 拉丁文 → 刻线 → 副题（terr-head）；衬线的正当性在"命名/题字"场景（星图名、领地名、书名），正文与控件一律无衬线。
- **图标**：天文仪器自绘语言（单 path、stroke 1.5）；不用通用图标库默认款，不用 emoji。
- **动效词汇**：入场=unsealRise 阶梯 / terrRise 级联；字幕=capfade（失焦到聚焦）；过场=领地航渡。新动效先用现成词汇表达，不够再发明。
- **亮度预算**：只给星，不给 UI。学习内容文字一律纯色，无流光渐变、无 glow。

## 3. 硬规则（四技能合并后对词峰生效的强制项）

**排版**
- 正文行长 65-75 字符/行；中文正文 30-45 字/行。
- 对比度 ≥4.5:1（大字 ≥3:1），用 `getComputedStyle` 实测（截图 OCR 不可信），**晴空/深空双主题各测一次**。
- 标题上下留白不对等（上多下少）；分组靠间距节奏，不靠包卡片。

**色彩**
- 一页一个 accent 主导，强调色区域 ≤10%；强调色表达优先级/状态，不做装饰。
- 语义色只表达语义（濒临遗忘红/待复习琥珀/已掌握银）；晴空下整套降饱和换暗琥珀系。
- elevation 只选一种语言（本项目=柔影 + 细边框二选一，不叠加）。

**布局**
- 一页 ≥4 种布局族，同族不连续重复；kicker（eyebrow）≤ 每三节一个。
- 卡片只在真需要分组表面时用，不嵌套卡片；Bento cell 数=内容数，不补空格。
- 首屏 hero：标题 ≤2 行、副题 ≤20 字、CTA 不滚动可见；导航一行放得下、高度 ≤80px。
- 移动端响应是结构性的（收导航/换布局），不是只缩字号。

**交互状态全周期**
- loading（骨架屏，与最终布局同形）/ empty（EmptyState 范本 + 引导行动）/ error（就地 + 恢复路径）/ disabled / success，缺一即半成品。
- 触屏目标 ≥44px；hover 不得是唯一路径（书脊卡/词根标签已有触屏兜底=范本）；按钮异步期间禁用+反馈。

**文案**
- 交付前重读所有可见字符串：AI 腔（假诗意、伪工匠标签）砍成朴素功能句；文案语域一页统一。
- 不造精确数字（92%/4.8×）；数据一律来自真 API 或明确标注示例。

## 4. 动效纪律（用户反馈史 + 技能规则合并，违者必返工）

1. **每个动效必须有动机**——一句话答"它传达什么"（层级/反馈/连续性/状态），答不出就删。"GSAP 能做"不是理由。
2. **运镜 ≠ 振动**：一切非用户触发的周期小幅位移都读成振动。要镜头动（航路滑行、聚焦、过场），不要景物抖。
3. 只动 `transform` / `opacity`；禁 `window.addEventListener('scroll')` 直挂（rAF 节流或 IntersectionObserver）；连续值不进 reactive state。
4. `prefers-reduced-motion` 必须支持（过场跳过、循环停播、位移降级淡入）。
5. 入场级联一页一次（首屏或关键卡组），循环动画只给"活着的系统"（时钟呼吸点、波形、星流），信息区静止。
6. 退场比入场快；产品页过渡 ≤300ms，不为频繁操作排队编排。

## 5. 反模式清单（AI tells——看到就改，不软化直接换）

- 通用图标库默认款混入仪器语言；emoji 当 UI 图标（项目铁律）
- 流光渐变文字、紫色 AI 渐变、玻璃拟态当氛围喷在 Operate 表面
- 每节一个 kicker、居中一切、等宽三卡网格 + 图标标题段落套餐
- ghost 水印大字（已删，永不再加——文字可读性 > 氛围）
- 圆角混用、阴影+边框双 elevation、装饰性 metric 卡无信息价值
- 晴空主题下渲染夜间氛围层（星尘全开/色光全开——白天看不见星星，静音是隐喻正确不是降级）
- 造出来的精确数字、只有名字的引用、em-dash 文案
- CTA 文案换行、同一意图多个 CTA 措辞

## 6. 交付前 Pre-Flight（≤2 轮验证，改完即停不过度打磨）

1. **一轮同查**：桌面 + 375px + 双主题；横向溢出；焦点顺序可见；触屏目标。
2. **对比度实测**：getComputedStyle 打三件套（color/background/rule），别信截图。
3. **空状态评估**：按新号走（库内几乎无学习数据），全零卡该隐藏的隐藏。
4. **e2e 必做**：真浏览器点过（历史上三次"build 绿但运行错"全是代码审不出来的）；圣殿类页面注意 swiftshader 坑。
5. **装饰量检**：晴空下这层静音了吗？它跟内容抢眼睛吗？——用户说看不清时第一反应是砍量，不是调参数。
6. **构建链**：`npm run build` 绿 → 服务端全资产 200 → 浏览器实测渲染（无 ViewError）。
7. **收尾**：删调试桩、清临时目录、时间戳 stamp 保持有效（下次启动秒开）。

---

## 7. 冲突裁决

1. 用户当轮反馈 > 本标准 > 通用技能规则。
2. `CREATIVE-DIRECTION.md` 的世界观是总裁判：任何效果答不出"它如何让暗物质变成星"，就不做。
3. 站用户角度不站工程角度：改动按"用户痛感"排序，答不出"用户直接好处"的工程美化砍掉。
