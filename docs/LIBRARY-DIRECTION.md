## 1. 世界观定位

书籍馆在词峰宇宙中的角色再定义：

- 单词 = 星体；**书 = 一颗「知识星体」**——读完一章，星体亮一分；读完一本，一颗完整的知识星点亮，并连入你的个人知识星座。
- **实体书 vs 数字书用两种材质语言区分**：
  - 实体书（原 20 本购书单）= **书脊**——插在木质轨道书架上，保留现有「悬停抽出」交互（这是实体书唯一正确的语言）；
  - 数字书（新增可读藏书）= **轨道星体**——悬浮在各自星域的轨道环上，缓慢自转。
- 馆区命名：领地名「书籍馆 LIBRARY」升级为 **「轨道书库 ORBITAL LIBRARY」**（TERRITORIES 映射与 NavBar 文案同步改）。
- 氛围定位 = **未来数字图书馆 × 天文台档案库**：安静、可以待很久的地方。不是商城书架。

## 3. 内容系统与数据模型

### 3.1 数据红线

不改任何现有表结构、不破坏现有 passages 机制。具体做法：

- 新增 `backend-node/data/library.json`：书的元数据 + 章节目录。
- 章节正文**进现有 passages 表**（seed 时插入，`type:'reading'`），复用全部既有机制：阅读答题入库（`/api/reading/result`）、阅读时长、词库命中分析、已学词绿色复现。为区分书章节与散篇，不动表结构的前提下在 `title` 用「《书名》· 章节名」命名约定 + library.json 里存 `chapter_passage_ids` 映射。
- 新增后端路由 `GET /api/library`（content.js 或新 library.js）：直接 fs 读 library.json 返回书架树（含每本书的进度，由前端从阅读记录算）。无 DB 迁移、无 schema 变更。
- 顺手完成挂起事项：`data/newpassages/p1~p8.json` 8 篇草稿 validate + merge 入库。

### 3.2 library.json 结构（草案）

```jsonc
{
  "books": [
    {
      "id": "lib-lighthouse",
      "title": "灯塔看守人的信",
      "en_title": "The Lighthouse Keeper's Letters",
      "author": "WORDPEAK Archive",
      "region": "literary",           // literary | science | classic
      "level": 1,                      // 星等 I~IV
      "hue": "var(--accent)",          // 星体主色（跟随主题）
      "one_line": "一位守塔人写给大海的十二封信，每封藏一个 hydro 家族词",
      "word_focus": ["hydro", "spect"],// 本书围绕的词根（写书时定向命中）
      "chapters": [
        { "no": 1, "title": "第一封信", "passage_id": 37 }
      ]
    }
  ]
}
```

### 3.3 内容规划（数量先行、宁精勿滥）

| 星等 | 定位 | 书目 | 来源策略 |
|---|---|---|---|
| 星等 I | 基础英语故事 | 2 本 × 4~6 章 | 原创短故事；现 passages L1 阅读篇 + 新稿改编聚合 |
| 星等 II | 生活场景阅读 | 2 本 × 4~6 章 | 原创；newpassages 8 篇中 L2 稿聚合 |
| 星等 III | 新闻/人文/科普 | 2 本 × 4~5 章 | **围绕词库词根定向创作**（经验：词根主题篇命中词库 5~36 词，老语料 0~3 词） |
| 星等 IV | 经典文学 | 2 本 × 4~5 章 | **公版节选**（Alice in Wonderland、Aesop 之外可选 Sherlock Holmes 选段——公版无版权风险），句级配 zh |

- 总量第一版：**8 本、约 40 章**。每章 10~14 句、3~5 题（沿用现有 passages 结构 sentences[{en,zh}] + questions[{q,options,answer,explain}]）。
- 「书」不是 PDF：书 = 有目录、有进度、有生词复现、有章末小测的**连续阅读单元**。写书时每章定向嵌入 5~12 个词库词，让「读完一本书」在圣殿里真实点亮一批星（复用阅读号已学的 exactMap/lemmaMap 命中管道，书章节零改动继承）。
- 后续待办并入本轮内容池：16 篇老空间主题语料（词库命中 0~3）不在本轮重写，标记为 M5。

## 4. 书架视觉：轨道知识星体（本轮视觉重点）

**不做**：封面网格、卡片阵列、商城瀑布流。

### 4.1 单颗书星（纯 CSS，不进 WebGL）

- 星体本体：`radial-gradient` 双停球（家族 hue 高光 20% + 深色收边），外圈 box-shadow 双层做大气（内亮环 + 极淡外晕——亮度预算：星体可亮，文字区不亮）。
- **轨道环**：椭圆 border 元素 `rotateX(72deg)` 3D 倾斜，环上一段 accent **进度弧**（conic-gradient mask 或 SVG ellipse dasharray）随读完章节增长。
- 星体自转：表面一层极慢平移的高光带（30s+，reduced-motion 关闭）——只动光不动形，遵守「非用户触发的周期小幅位移=震动」教训。
- 状态档位（与圣殿 halo 同语言）：未读=暗尘（低饱和）、在读=家族色 + 进度弧、读完=金色柔晕。
- hover：星体 1.06 倍 + 大气增亮 + **书签卡**从星体侧展开（探测设备扫描结果风：mono 章节刻度 + 衬线书名 + 星等 + 一句话简介 + 「进入阅读 →」）。点击 = 领地过场 → 阅读舱。

### 4.2 星域排布

- 每个星域一个横向「轨道带」：书星沿椭圆轨道错落分布（确定性伪随机散布，按书 id hash——与 SkySketch 同哲学），不同高度制造纵深。
- 星域标题用 terr-head 语言缩制版：mono 拉丁名 → 衬线中文 → 刻线。
- 全页滚动时书星三层视差（近层多漂），复用 StarFieldBackdrop 的 wheel-boost 模式；书架页顶部 StarFieldBackdrop 照常透进（透明 view 已具备）。
- **个人知识星座**区：收藏书之间的金色连线（呼应终幕星座/SkySketch），空态文案「收藏一本书，连起你的第一段星轨」。

### 4.3 纸书指南针（保留区）

- 现有书脊抽书交互、相邻书物理倾斜、roadmap 四步全部保留——只换区头语言与星域分组一致。
- 定性说明写进 UI 一句话：馆藏在读、纸书在练（「架上的是星，桌上的是书」式文案，定稿再议）。

## 5. 阅读舱（自主阅读）

新视图 `BookReaderView.vue`（走 `lazyView()` 懒加载 + `pending*` 深链惯例：`store.pendingBook = { bookId, chapterNo }`，书架/收藏/推荐三处都可深链进舱）。

### 5.1 舱内结构（从上到下）

1. 舱头：书名衬线大字 + mono「CHAPTER N / TOTAL」刻度 + 星等 chip + 进度微条；
2. **双模式**：
   - **流式连读（默认）**：整章段落流式排版（不再是逐句卡片），大字号优先（用户明确偏好），行距 1.9+；每句 hover 浮现极淡的下划刻线，点击该句 → 句卡展开；
   - **逐句精读**：沿用阅读号现有整句模式（句子卡 + 中文辅助开关 + 点词），作为「难句工具」按句切换。
3. 点词：沿用阅读号 token 化管道（exactMap + lemmaMap）——词库词点击弹 LookupMenu/词星卡，非词库词点击弹「AI 词义速查」（走讲解接口的词级模式，降级时显示本地词典匹配结果）；
4. 章末：沿用 passages questions（答题入库走现有 `/api/reading/result`）+ **章末生词表**（本章点过的生词 + 该书 word_focus 命中复现的已学词）；
5. 舱尾：「下一章 →」大按钮 + 读完本书 → 全屏点亮仪式（复用 `wv:wordLit` 语义的书籍版：回书架看星体升金）。

### 5.2 阅读时长 / WPM

阅读舱记录阅读秒数（沿用 wv_reading_time localStorage 通道 + WPM 结算展示在章末，不强制）。

## 6. AI 讲解系统（「他可以讲解」）

### 6.1 后端：新路由 `POST /api/explain`

- 入参 `{ sentence, title?, mode?: 'sentence' | 'word' }`。
- LLM 优先（沿用 ai.js 的 Anthropic haiku → Gemini 双链 + 15s 超时），要求输出**短小中文 JSON**：
  `{ "translate": "整句翻译", "grammar": [{"point":"语法点","note":"一两句讲解"}], "sense": [{"word":"词","note":"这个词在此处的意思/用法"}], "expression": "值得学的表达，一句话" }`
- **本地降级**（无 key / 调用失败，绝不白屏）：
  - sentence 模式：sentences 表如带 zh 直接回填 translate；语法点用简单规则表（时态标记词/从句引导词/被动 be+done 粗匹配）；sense 走词库 461 词命中 + 词根故事；
  - word 模式：词库查词（释义/词源/例句）+ 词形还原。
- 无状态（不加表）：结果按 sentence 文本 hash 做**内存 LRU**（容量 ~200），同句二次点开秒回。
- 频控：每用户每分钟 20 次，超限返回友好 err（与 ai.js 一致的 err/ok 壳）。

### 6.2 前端：句级「透镜」交互

- 每句 hover 右侧浮出一个极简仪器钮（「句法透镜」，自绘图标——小放大镜 + 星芒，语言与 NavBar 仪器图标同族）；
- 点击 → 句下方展开**讲解卡**（探测设备扫描结果风）：mono 「LENS · SCAN」头 → 整句翻译 → 语法点刻线列表 → 词义列表 → 表达学习。纯色无流光，unsealRise 阶梯入场（与词卡同语言）。
- 加载中 = 仪器扫描态（mono 「SCANNING…」+ 细刻线推进，不做转圈 spinner）。
- 生词在讲解卡里可点击 → 直接进词星卡并落库复习（闭环）。

### 6.3 讲解的三层（明确边界）

| 层 | 内容 | 来源 |
|---|---|---|
| 句 | 翻译/语法/语境词义/表达 | /api/explain（本轮新增） |
| 词 | 释义/音标/词源故事/同族 | 现有 WordPanel + 词源 API |
| 章 | 章末测题 + explain 字段 | 现有 passages questions |

不做的：全篇 AI 总结代读（违背「自主阅读」）、无中生有的 AI 人设对话（ai.js 只做教练不做陪聊）。

## 7. 学习闭环与星系联动

用户 brief 的闭环「输入 → 理解 → 记忆 → 使用 → 复习」在词峰的落点：

```
输入    阅读舱流式连读（大而易读）+ 分级星等推荐
理解    句法透镜（AI 讲解）+ 中文辅助 + 词星卡词源
记忆    点词自动进复习队列（现有 api_learnWord）+ 章末生词表
使用    章末测题 + （后续轮）写作模块引用本书表达
复习    已学词在书内绿色复现（现有 known 态管道）+ 圣殿复习/错题暗星
```

- 分级推荐：书架顶部「为你导航」一行 2~3 颗推荐书星，规则极简（不是 AI 黑盒）：按 store.states 已学词量 + 各书 word_focus 命中率排序——「你已点亮 30 颗 spect 星 → 推荐《观星者手记》」。这满足 AI 助手「推荐阅读」的可用版本，后续再接 plan.js。
- 读完一本书 → 书星升金 + Dashboard「你的天空」可感知（不在本轮强行做天空新增星，标记为后续轮）。

## 8. 性能与可读性红线（继承教训）

- 书架页**不进 WebGL**：书星 = 纯 CSS transform/gradient + 视差层 Canvas2D 复用现有模式；Three.js 只存在于圣殿。
- StarFieldBackdrop 书架页照常（透明 view 已具备），书星自身发光受限——亮度预算：**星体可亮、文字区不亮**，晴空主题下书星降饱和 + 去外晕（「白天看不见星星」隐喻正确）。
- 讲解卡、书签卡全部 DOM，无高频动画；reduced-motion 全局跳过。
- e2e 沿用无头 Chrome + CDP 模板（.claude-tmp/e2e-*.mjs），书架/阅读舱/讲解三组用例；已知坑规避：全新 profile、swiftshader 只给 WebGL 页、DOM 断言不靠截图 OCR。

## 9. 明确不做的事（本轮边界）

1. **逐星异材质 Shader**：第一轮已确立「钢与月长石」方向——家族身份靠几何与光，不靠花色。brief 中「每星球独特 Shader/表面纹理」以现有的家族几何差 + 大气 + halo 分档兑现，不推翻已批方向。
2. 景深 DOF：lowEnd 机 Bloom 已是负担，DOF 延后（做性能审计后再议）。
3. 商城式阅读器（划线笔记云同步、PDF 上传）：与世界观无关。
4. 全篇 AI 代读/代总结。
5. 老空间语料 16 篇重写：挂 M5，不混入本轮验收。

## 11. 终验标准（对照用户原话）

- ❌ 不能像「书城/图书馆网站」；❌ 不能像「AI 生成的封面网格」；
- ✅ 像一座**可以待很久的未来档案库**：书星在轨道上悬着，收藏连成星座，读一章亮一分；
- ✅ 用户第一次进书库：「这些书是这个世界里的东西」，而不是「这里推荐了 20 本淘宝书」；
- ✅ 自主阅读：从书架到读完一章再到生词落库，全程不出宇宙（领地过场衔接）；
- ✅ 讲解：任何一句点开就有翻译 + 语法 + 词义，无 key 也不白屏。
