# 创意方向文档 · WORDPEAK 词峰

> 状态：待用户审批（2026-10-14）
> 定位：把现有"词汇圣殿"从"带 3D 的学习应用"升格为一部完整的数字世界体验

## 1. 项目概念名

**词峰 WORDPEAK — 一部会因你而亮的语言星图**
（体验副题：*The Night Sky of English*）

## 2. 一句话创意

> 每一个英语单词都是一颗星，词根是星座，而**你的记忆是这个宇宙里唯一的光源**——你学，宇宙便亮。

## 3. 核心隐喻

**词源即星图（Etymology is a Star Chart）**

- 拉丁/希腊词根 = 星座：在人类头顶亮了几千年，位置几乎不动（spect / hydr / port……）
- 派生词 = 由星座孕育出的星：461 颗，真实词源数据决定它们的轨道、位置、家族
- **未学之词 = 暗物质**：它们存在——银灰钢雕塑悬在虚空里——但对你不发光
- 学习数据 = 光：不是装饰性发光，是这个宇宙的物理法则。**宇宙的亮度就是你的词汇量**

这条隐喻是所有视觉决策的裁判：任何效果如果不能回答"它如何让暗物质变成星"，就不做。

## 4. 数字世界描述

一个连续的、无页面的空间：**词峰宇宙**。

- 大部分是无边的暗与星海（纵深三层球壳星尘 + 星云）
- 唯一的"地"是中央一间光池展厅（atrium）——冷岩地板中央悬着玻璃晶体**「词峰之心」**，
  塔尖一盏暖灯，是这个寒冷宇宙里唯一的暖点
- 40 个词根家族以三环槽位围绕之心悬浮，每族一圈细轨道环 + 黄金角向日葵散布的词星
- 没有轮播、没有卡片网格、没有"板块"。整个世界只有一个空间，**相机是用户唯一的身体**

## 5. 用户情感旅程

| 阶段 | 情绪 | 触发 |
|---|---|---|
| 进站 | 敬畏 | 黑暗中只有一颗星在呼吸 |
| 开场 | 惊奇 | 那颗星被"解封"，拉远后显出整片星海 |
| 航行 | 好奇 | 滚轮不是滚动页面，是驾驶相机穿越星族 |
| 解封 | 惊喜 | 每颗星里都藏着一座档案馆（词源/例句/易混辨析） |
| 点亮 | 成就 | 学会的星真的亮了，宇宙在记录你 |
| 终幕 | 归属 | 相机拔升——属于你的星连成了**你自己的星座** |

## 6. 体验流程

```
进入(引力捕获) → 探索(航行) → 互动(解封词星) → 发现(星族浮现/隐藏细节) → 蜕变(我的星座)
```

- **进入**：boot 引导页 = 「词峰引力」，三点脉动（已有）
- **开场**：创世纪运镜（已有 _pickIntroWordId + 绕词特写，需强化叙事，见幕 0）
- **探索**：滚轮 = 沿预烘焙航路飞行（FlightController 已有）；一碰即脱离航路自由漫游，
  「继续航行」1.1s 无缝回航（已有）
- **发现**：航线扫过之处，家族星座连线浮现（sweep 已有）；hover 星晕点亮、光标斥开星流（已有）
- **蜕变**：**新增终幕**——不是 footer，是一个只属于当前用户的星空结局

## 7. 场景分解（六幕）

### 幕 0 · 创世 GENESIS（升级现有开场）
黑屏中一颗星被选中（优先点亮过的词，否则大族首词）→ 相机绕词特写 2s →
拉出 2.6s，**拉出过程中该词所属家族的星座连线当着用户的面绘制成型** →
落入全览 (0,13.5,50) 无缝挂挡。衬线宣言字幕：「每一个词，都始于一颗星」。

### 幕 1 · 全览 THE OVERVIEW
航路起点，40 族星图尽收，HUD 刻度轨亮起。

### 幕 2 · 星族巡游 THE FAMILIES
逆时针巡游外环，sweep 扫到哪个家族，哪族的刻线环 + 星座连线浮现（setSweep 已有）。

### 幕 3 · 词之心 THE HEART
低角英雄位仰视晶体，壁炉光 ×1.5、光帘 ×1.45（atrium.setFlight 已有），全宇宙唯一的暖。

### 幕 4 · 解封 UNSEAL
点任意星：相机收到 16~26 距离聚焦（_focusOn 已有），词档案五级阶梯升起
（unsealRise 已有：head .05 → root .13 → meaning .2 → ex .3/.42 → more .52）。

### 幕 5 · 我的星座 MY CONSTELLATION（全新终幕）
滚到航路尽头，相机拔升俯瞰，HUD 退场 → 属于当前用户的已学词星之间浮现金色连线，
连成一幅**以学习数据生成的、独一无二的星座** → 生成星座名
（如「观星者 · SPECT 族群」）+ 一行字：
「你点亮了 N 颗星，还剩 M 颗在暗处等光」→ 可导出星图 PNG 分享。

## 9. 动画系统（运动三定律）

1. **一切运动有质量** —— 位置/注视/侧倾全部惯性 lerp，转向带 bank ±0.05rad，绝无线性位移
2. **一切入场有级联** —— 任何揭示都是 stagger 阶梯（unsealRise 0.45s / heroRise 五级 / sweep 渐显），
   单元素入场视为错误
3. **一切状态有过渡** —— 字幕失焦到聚焦（capfade + blur 6px），章节字幕字距收拢 0.55em→0.34em，
   无状态是瞬切的

现有动画语汇统一归档：`unsealRise / capfade / chapterTrack / chapterFade / heroRule / heroRise /
bank / sweep / clockPulse / starTwinkle`。终幕星座连线绘制用 timeline 精确控制逐段 stagger。

## 10. 视觉风格指南

- **色彩**：基底 `#05070f`；accent 青 `#22d3ee` / 紫电 `#a78bfa` / 品红 `#f472b6`；
  **唯一暖点** `#f2ead8`（词之心塔尖灯）。克制：亮度预算只给"星"，不给 UI
- **材质**：钢与月长石冷调谱系（206~240° 蓝带、饱和 5~14%）；晶体 transmission 玻璃
  （低端换抛光钢）；地板湿石化 roughness 0.2 拖出光池软反射
- **打光**：冲击力 = 亮部更亮 + 冷轮廓勾边 + 纵深雾光 + 电影暗角，**不是全场提亮**
- **字体**：衬线大写字距 3px"星图命名式"（家族名/宣言）+ mono HUD 小字；
  学习内容纯色、不流光、不 emoji
- **空间法则**：只有光池是"地"，其余皆悬浮；**黑暗是内容，不是空缺**——暗物质本身要被读懂
- **禁止**：霓虹赛博、数据流、蓝色渐变 SaaS、卡片网格、shimmer 流光、14 项导航挤一排

## 11. 技术架构

现有基座不动：
- Vue 3 + Vite + Pinia + 原生 three.js；引擎状态机 intro→resume→flight→focus→free
- flightpath.js 预烘焙 CatmullRom 双曲线（位置+注视，弧长参数化）
- CSS2D 标签距离退隐；Bloom postfx（lowEnd 跳过）；461 星单 draw call halo
- CPU 星流力场（1000 粒、光标斥力、lowEnd 不开）

新增模块：
- `galaxy/constellation.js` — 终幕：已学词连线星座生成 + 绘制动画 + 星座名生成
- 星火问答桥接 store/api（答题 → 星提亮档位持久化，写入词强度）
- 星图导出（renderer 截帧 + 叠加星座名/数据 → PNG 下载）
- 幕 0 家族星座"当面绘制"（intro 阶段对选中词所在 cluster 注入连线绘制动画）

性能红线：中端机 60fps；现有降级链全部保留。

## 12. 为什么这个体验是独一无二的

1. **数据即世界** —— 40 个真实词根 × 461 个真实派生词直接生成几何；学习记录直接决定宇宙亮度。
   别人的宇宙是美术画出来的，词峰的宇宙是词源数据长出来的，并且因每个用户而不同
2. **学习即观星** —— 把最枯燥的事（背单词）编码成最有画面感的事（点亮恒星）。
   空间记忆本身是记忆科学，星座 = 用户自己的记忆宫殿
3. **结局不是 footer** —— 绝大多数网站的结尾是版权栏；词峰的结尾是一幅只属于你的、
   可分享的星座图。第一次让"学习进度"成为值得晒出去的情感物件

## 第二轮 · 领地化（2026-10-14 已实施）

第一轮把圣殿做成了世界；第二轮消灭"退出圣殿的那个瞬间"——**一个宇宙，不是十六个页面**。

概念：圣殿是中央大厅，每个学习模块是宇宙深处的一块**领地**。落地四件事：

1. **领地过场（TerritoryTransit.vue）**——视图切换升格为电影语言：全屏径向星流航渡
   + 领地名衬线浮现（回声谷 · ECHO CANYON）。App.vue 的 `displayView` 落后 `store.view`
   320ms，在过场掩护下换视图；快速连切由 seq 序号守卫；prefers-reduced-motion 直接跳过。
   15 个视图的领地名集中在 App.vue `TERRITORIES` 映射（错题本 = 暗物质区 DARK MATTER）。
2. **共享环境天空（AmbientField.vue + three/ambient/AmbientSky.js）**——Three.js 三层视差星野 +
   程序化星云，30fps 封顶、页面隐藏暂停、光标/滚轮视差、主题跟随（宣纸只留极淡墨尘）；
   进圣殿/官网时歇业。WebGL 不可用自动退回 Canvas2D 星尘（StarFieldBackdrop 保留为兜底）。
   领地页头另有 TerritoryMark 专属星图，观星台首屏有 HeroOrrery 实时天体仪。
3. **回声谷（ListeningView 领地化）**——听力列表页从卡片网格改为**信号轨道**：领地页头
   （`.terr-head` 全局语言：kicker→衬线大字→拉丁文→刻线→副题）+ 全宽信号行（mono 序号、
   确定性小声纹 7 柱、hover 逐柱起浪 srEcho、左缘 accent 刻线）。播放器/波形/答题功能零改动。
4. **观星台（DashboardView + SkySketch.vue）**——首页新增「你的天空」星图速写：461 词按词根
   家族分扇区铺天盘，已学 = 金星（终幕星座同源金）+ 星座链连线，未学 = 暗尘；点亮星回圣殿
   （`selectWord + setView('galaxy')`）。文案对齐：nav/帮助/命令面板/书馆全部改称「回声谷」。

### 第三轮 · 剩余领地收口（2026-10-14 已实施）

- **暗物质区（MistakesView）**——错题 = 未点亮的星。领地页头 + 统计 chip「N 颗星等光」；

  全局 `.dm-star/.dm-lit/.dm-hover` 语言（styles.css），点词卡仍深链回圣殿。
- **阅读号列车（ReadingView）**——领地页头（READING RAILS），正文阅读/WPM/点词功能零改动。
- **信号行语言全局化**——`.signal-list/.signal-row/.sr-*` 从回声谷 scoped 提升到 styles.css，
  成为所有领地列表页的共享条目语言。
