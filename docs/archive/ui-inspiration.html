01 灵感画廊
Dribbble↗
设计师作品展示,找视觉风格、创意交互的首选。搜界面类型如 "dashboard"、"profile"。
视觉 / 概念稿
Behance↗
Adobe 旗下,完整项目案例多,适合研究整套设计系统的思路。
完整案例
Mobbin↗
真实 App 截图库,按流程分类(登录页、设置页、付费页),做 UI 时最实用。
真实产品
Land-book↗
专门收集落地页 / 官网设计,做网页时直接抄布局。
落地页

04 设计系统与规范
Refero↗

真实界面
shadcn/ui↗
