# WordVerse（词境）全面优化需求清单

## 项目背景

WordVerse 是一个 3D 沉浸式英语学习网站。

当前已有：

- Vue 3 前端

- Pinia 状态管理

- Express 5 后端

- node:sqlite 数据系统

- Three.js 3D场景

- 461个英语单词

- 40个词根家族

- 15个功能视图

- 星球、词根、学习、听力、错题等功能

目前核心功能已经存在。

现在不是重新开发功能。

主要任务：

对 WordVerse 进行视觉重构、学习体验升级、内容体系扩展、性能优化。

目标：

打造一个真正沉浸式、高效、有学习氛围的英语学习宇宙。

==================================================

# 一、整体产品定位升级

当前问题：

现在更像：

“一个带3D效果的英语学习网站”

而不是：

“一个用户愿意长期学习的语言成长空间”。

优化目标：

WordVerse 应该成为：

一个结合：

- 沉浸式3D体验

- 科学英语学习方法

- 丰富学习内容

- 个性化成长系统

的个人英语宇宙。

用户进入后应该感觉：

“我要回到我的英语学习空间。”

而不是：

“我打开了一个3D网页。”

==================================================

# 二、解决AI生成感问题（重点）

当前视觉问题：

- 页面像AI模板生成

- 缺少原创创意

- 元素像素材拼接

- 缺少品牌视觉语言

- 视觉效果普通

禁止：

- 黑色背景+蓝紫渐变科技风

- 普通发光星球

- 随机粒子效果

- 玻璃卡片堆叠

- 通用未来UI

- 普通3D模型

不要简单增加特效。

需要重新进行：

Visual Art Direction（视觉艺术指导）

要求：

每一个元素都必须有设计理由。

不要问：

“怎么让页面更炫？”

应该问：

“这个元素为什么存在于WordVerse世界？”

==================================================

# 三、建立WordVerse原创视觉语言

不要只是：

英语 + 宇宙 = 星球。

需要建立独特世界观。

推荐方向：

未来语言天文馆。

融合：

- 天文学

- 语言探索

- 知识地图

- 未来教育

视觉元素：

- 星图

- 天文仪器

- 语言轨道

- 知识结构

- 探索设备

让用户看到视觉就知道：

这是WordVerse。

==================================================

# 四、3D空间体验升级

当前问题：

- 空间感不足

- 星球像普通模型

- 没有真实宇宙层次

- 缺少探索感

优化：

建立三层空间。

## 前景层

增加：

- 星尘

- 漂浮设备

- 光粒子

- 环境细节

## 中景层

增加：

- 词根星球

- 学习区域

- 交互对象

## 后景层

增加：

- 银河

- 星云

- 深空结构

目标：

让用户感觉进入一个真实空间。

==================================================

# 五、Camera电影级体验

当前问题：

页面切换像普通网页。

优化：

不要使用普通跳转。

加入：

- 镜头推进

- 镜头拉远

- 平滑飞行

- 景深

- 空间穿越

- 星流转场

例如：

点击词根星球：

不是打开页面。

而是：

镜头穿越星流进入知识区域。

==================================================

# 六、星球系统优化

当前问题：

星球只是装饰。

升级：

每个词根星球成为一个独立知识世界。

每颗星球需要：

- 独特造型

- 独特材质

- 独特环境

- 独特动画

增加：

- Shader材质

- Atmosphere效果

- Fresnel边缘光

- 表面纹理

- 环绕粒子

==================================================

# 十一、学习方式简化

当前问题：

功能很多。

但是用户不知道：

第一步做什么。

优化：

首页增加：

今日学习任务。

例如：

今天：

- 学习10个新词

- 复习20个旧词

- 阅读1篇文章

- 听力训练5分钟

用户点击：

开始学习。

减少选择。

降低学习门槛。

==================================================

# 最终目标

“一个有星球背景的英语网站”。

“一个具有原创世界观、科学学习方法、沉浸式体验的个人英语成长宇宙。”
